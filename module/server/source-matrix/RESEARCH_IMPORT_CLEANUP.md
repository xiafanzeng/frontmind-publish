## 旧中文文件名

优先使用同内容原文件重新上传，由内容指纹确定数据集身份，再使用明确传输的原始文件名更新名称。重用 confirmed 记录时不改变其记录、version 或历史任务快照，不生成副本。

仅能保守识别、可逆恢复的历史 mojibake 可以在读取展示时纠正；无法可靠还原（例如字符已被替换或丢失）时保留原值并通过同内容原文件重新上传修复。不要对全表名称无条件转码，也不要改写 Excel 二进制或所有单元格。

逐项验证新上传、列表、刷新、重复上传复用和替换后的名称；分别核对记录内容。历史任务快照属于当时状态，不通过重命名可选文件静默重写。
