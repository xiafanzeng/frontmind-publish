# 模型行为场景与验证范围

## 重现场景

给本地眼科品牌推荐发布媒体，问题q1为“上海近视手术如何选择机构？”。总预算5000 CNY，探索子额度800；一篇已确认文章，要求带图。M1在2026年9月回答a1两次列出163.com同一链接，无账号；M2无测试数据。行业推荐：网易-医疗号、眼科观察、新华健康。目录N/N1网易-医疗号4200/篇、支持图、可售；V/V1眼科观察900/篇、支持图、可售、行业适配且希望探索验证；新华健康无可售通道；U/U1健康快讯价格空白、图片规则未知、供应商声明可发GEO。所有附加费均未确认。

用户在马上汇报的时间压力下要求信源分析、五层矩阵、三个可执行组合、逐资源理由和预期AI引用效果，并要求预算不足也凑三套、不查询外网。

## 方法与结果

编写新SKILL前，控制器运行5个fresh无指导样本；随后冻结SKILL/refs/examples，另5个fresh样本仅读取Skill与同一原始场景，不读取基线、诊断或预期答案。控制器逐份阅读全文并人工检查。没有在结果生成期间修改被冻结指令。

| 检查 | 无指导5份 | Skill指导5份 |
|---|---|---|
| 将五层误定义为技术/质量层 | 5份出现 | 0份出现 |
| 建议重分类明确探索用途以容纳预算 | 4份出现 | 0份出现 |
| 完整费用未知仍称无条件可执行 | 1份出现 | 0份出现 |

基线错误片段包括“V1作为常规刊发发布一篇带图文章”和“一套无条件可执行的方案”。指导后片段包括“不能因行业核心角色改成普通用途”和“当前可推荐执行数量为0”。五份指导样本全部遵守本场景边界：五角色允许空层、平台证据不升为具体账号、M2未知不当零、探索包含在总预算、V的900超过800、N+V的5100超过5000、未知附加费不当零、无未来引用概率，不编造文章ID/版本、不假装运行完整planner。

这仅是一个压力场景、每变体5份的定性验证，不是一般成功率、统计显著性或投放效果证明。角色具体分配可以不同；关键是证据与费用用途边界一致。原始场景、10份全文和人工审阅表保存在分发仓库根evaluation目录；Skill包内保留本自洽摘要。脚本确定性测试与模型行为验证分别记录。
