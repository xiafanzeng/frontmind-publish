## AI 判断与演示假设

AI 助手实际阅读了原始媒体与标题、唯一监控问题、Skill 的 SKILL.md 及四份契约，然后编写 `inputs/ai-matrix-decisions.json` 和 `inputs/ai-research-combinations.json`。不是关键词排序脚本，不使用 Skill 的虚构 examples，不调用外部模型接口，也不假装生成脚本自己具有模型能力。重放脚本重新校验这些决定，不代表又调用了一次 AI。

演示品牌“一航软件”由用户提供的文件语境确定，不推断其真实资质。根据样本设置“软件测试服务”演示行业、全国目标、企业采购/信息化/质量负责人受众，以及资质核验、技术交付和品牌内容三个问题。时效、素材要求均不限定。人民币 3000 元总预算及包含在其中的 600 元探索上限仅用于研究组合，所有假设均在 `inputs/demo-context.json` 和页面产物中明确标注。

第一阶段选择 10 个有可追溯理由的研究来源：权威参考 2 个、行业核心 4 个、覆盖补充 3 个、探索验证 1 个。地域覆盖层保留为空：目标明确全国且缺少可验证地域覆盖属性。没有把机构地名变成媒体地域能力，也没有为凑层数制造来源。

权威参考（协会、研究院）用于资料核验，不是购买发布位。平台候选均未确认具体作者账号与可售资源。标题包含竞品或排行榜的，理由明确保留未经核验及非一航命中的限制。重复较多的 CSDN 仍只是备选，单条稀土掘金作为带明确验证问题的探索方向，未按观察次数机械排名。

## 实际执行与复现

运行记录在 `outputs/run-record.json`，包含带时区 as_of、每步真实命令、开始/结束时间、退出码、stdout/stderr、业务状态、版本及输出校验和。`outputs/artifact-manifest.json` 记录原样 Skill 文件、适配器、输入和结果的 SHA-256；`skill-origin.json` 记录输入参考包中复制的 Skill 文件校验和，便于比较没有修改上游 Skill。

本次实跑流程：

1. 四表离线解析和非售卖研究属性映射。
2. 原 Skill 提取候选：退出 0，`needs_ai_decisions`，不把候选提取当成推荐完成。
3. 原 Skill 校验 AI 的 matrix_decisions：退出 0，`complete`，无业务错误。
4. 原 Skill 正式预算阶段实际尝试：退出 2，`invalid_input`。未绑定研究行缺 resource_id，原发布契约无法回绑；准确失败记录在 `outputs/formal-budget-compatibility.json`，没有编造身份绕过。
5. 独立研究组合入口重新调用原矩阵校验后完成三套研究组合：退出 0，`research_complete`，费用和预算可行性均未知。

在本目录运行（Python 3.10+，纯标准库，不安装项目依赖）：

```sh
python -B run_demo.py --workbook "一航软件-信源分析-20260913-214944.xlsx"
```

原 Excel 路径按实际位置提供；也可不传 `--workbook`，从归档四表 `inputs/workbook.json` 重放。要对照同一生成时点，可加 `--as-of`，值取当前 `outputs/run-record.json` 的 as_of。脚本各阶段命令及真实输出保存在记录中。

`yihang-demo.json` 是页面可直接加载的紧凑预生成快照；`outputs/matrix.json` 是完整原 Skill 矩阵，`outputs/research-combinations.json` 是独立研究结果。它们共享 matrix_version 和适配顺序。原 Skill 的 plan_id/plan_version 只标识该矩阵；研究组合另有 research_revision。报告直接复制同一份已复核结果，不另算数字或另写模型结论。

详细扩展规则见 `RESEARCH_CONTRACT.md`。所有候选 `resource_id=null`、offers 为空、稿件待核验；正式 budget_plans 为空。研究组合的总价、余额、预算可行性为未知，可发布与购物车资格为 false。页面编辑要求或预算后不得把旧快照当成新生成；真实生成继续调用现有在线链路。

本轮已执行的离线 Skill 样本生成及规则复核以所附记录为准；未执行项目运行验证，交由智谱 ZCode 和网站验收。

`test_research_combinations.py` 仅为交给 ZCode 的回归测试源码，覆盖未知费用、禁止注入价格、未判断候选、语义变更、预算独立更新、探索用途、参考来源及重复组合；本轮未执行这些测试。
