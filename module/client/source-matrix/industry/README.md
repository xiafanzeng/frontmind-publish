# 行业信源分布

`IndustryDistribution.tsx` 导出 `IndustryDistribution({batches,loading?,error?,onRetry?})` 和 `LiveIndustryDistribution()`；前者用于独立样本查看，后者仅请求同源真实 `/source-distribution`，从不将错误或空库替换为样本。真实服务只在 `status: ready` 时消费批次。

`yihang.ts` 导出 `YIHANG_SOURCE_BATCH` 与 `YIHANG_SOURCE_PROVENANCE`。样本来自四表全量导出，不参与推荐内核有效 detail、aggregate_ids 或采购映射。原始行号只用于文件追溯，不是回答或引用事件 ID。

## 可复现转换

在仓库根目录使用现有 Python 3（标准库，无依赖安装）：

```text
python module/scripts/convert-source-distribution.py ../references/一航软件-信源分析-20260913-214944.xlsx
```

脚本只进行离线 XLSX 解包与转换，默认输出 `yihang-data.json`，可传第二参数指定输出路径。JSON 保存批次、SHA-256、四工作表全部单元格地址、原值、原始存储值、类型、样式索引、公式、行号、明细字段映射及对账数字。`内容状态` 从内容统计 B 列按 D 列原 URL 精确对应；两张统计表仅对账，不与明细叠加。

本包实际离线转换核对：文件 SHA-256 `639e43735887ff20852f99aa4bc643853259dbd7f44aba163598064720a60e0d`；详细表格 502 条，URL 114，媒体名称＋URL 61 组；七字段组合 216，额外完全相同行 286；两个统计表合计各 502。四模型 118/282/53/49，2026-09-12 为 262 条、09-13 为 240 条。媒体名空 3 条按域名显示，原值仍为空。

## 口径与交互

- 行业、模型及引用日期共同过滤；媒体选择只过滤右表，不改变占比或两张分布图的分母。引用次数按原始导出行计数，不推断独立回答事件。
- 媒体按原名称＋URL 聚合；内容按原 URL 聚合；无内容 URL 的行独立保留、排除发布时间图分母。文件重复批次按 SHA-256 防重，文件内相同行不删。
- 类型图以引用记录为分母；发布时间图以去重内容 URL 为分母。无媒体类型、发布时间时为未知；同 URL 日期混合缺失/无效或多个发布日期冲突时也为未知。
- 发布时间日差：0–1、2–7、8–30、31–365、366–1095、1096+。未来、缺失、冲突日期为未知。按月的基准日为所选月最后一天；日期范围按结束日期；未限定结束日期取已导入统计期间末日与实际引用日期的较晚值，并显示基准日。
- 原生 select 与 month/date 输入接受浏览器/操作系统弹层及键盘行为；字段有标签，日期错误为文本。筛选、排序、页码和媒体范围通过 `sm*` 查询参数恢复，保留原 task/draft/version/hash。无写入和采购操作。
- 独立 CSS 限定在 `.fm-media .sm-industry`；外层继续复用 MediaShell 的字体、品牌、页面滚动和底部购物车，不新增全屏高度。
